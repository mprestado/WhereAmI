# Changelog

## 0.5.0 — 2026-11-24

- Added count targets to objectives and sub-objectives. Increase or decrease the count from the goal, the task list, or the overlay.
- Added percentage progress beside the goal name in the overlay, adjustable text size, and window resizing.
- The overlay and main app can open side by side. Closing the main window hides it in the Windows notification area.

## 0.4.1 — 2026-11-24

- Added previous and next objective buttons at the bottom of the expanded Windows overlay.

## 0.4.0 — 2026-11-24

- Added the Windows Task overlay with a compact checklist that stays above other apps and collapses to a single row.
- Completing work from the overlay updates the same workspace. Open the full app to return to the original window size and position.

## 0.3.0 — 2026-11-24

- Anchored the objective navigation at the bottom and added previous and next buttons, wheel navigation, and press and drag on desktop.
- Added an account action to copy this device's goals, tasks, and progress. The local copy stays available and existing account records are kept.

## 0.2.0 — 2026-11-24

- Replaced the goal's multi-column and long-list views with a centered, horizontally snapping objective carousel.
- Added clickable objective dots, collapsible sub-objectives, and a compact goal progress indicator.
- Made goal content read-only during normal use; completion checkboxes are the direct in-place actions.
- Added strikethrough for completed objectives and sub-objectives.
- Moved goal title, objective, optional-state, and ordering edits into Goal Settings.
- Kept existing local and Supabase workspace records on the same data model.
